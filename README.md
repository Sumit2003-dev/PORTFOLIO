* **Dual-View Skills & 3D Interactive Cosmos**:

  * *3D Cosmos*: Fully interactive WebGL galaxy with drag-to-rotate, planetary orbits, and raycasting hover inspection.

* **Ask Sumit AI Assistant**: Floating hybrid chatbot featuring an instant 16+ topic semantic router with zero client-side API key exposure (support for optional server-side AI proxy).

## 💻 Local Development Setup

### Prerequisites
* Node.js (v18 or higher recommended)
* npm or pnpm

### Quick Start
```bash
# 1. Clone the repository
git clone https://github.com/Sumit2003-dev/PORTFOLIO.git

# 2. Navigate to project root
cd PORTFOLIO

# 3. Install dependencies
npm install

# 4. Start local development server (runs on http://localhost:8080)
npm run dev

# 5. Type-check & build for production
npx tsc --noEmit
npm run build
```

## 🚀 Deployment

### GitHub Pages (Automated)
This repository includes a preconfigured GitHub Actions workflow in [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml).

1. In your GitHub repository, go to **Settings** > **Pages**.
2. Under **Build and deployment** > **Source**, choose **GitHub Actions**.
3. Push any commit to `main`, and your site will automatically build and publish to:
   ```
   https://sumit2003-dev.github.io/PORTFOLIO/
   ```

### Vercel / Netlify
1. Import this repository into Vercel or Netlify.
2. The framework preset is automatically detected as **Vite**.
3. Build command: `npm run build` | Output directory: `dist`.
